# UI/UX Workstream

This document contains current interaction contracts, design rules, and unresolved UX decisions. Dated feedback, superseded alternatives, and historical implementation notes are preserved in [`docs/ui-ux-archive.md`](ui-ux-archive.md).

## Current product direction

- Lagrange uses a native Android shell with Home, Libraries, and More as primary destinations.
- Home aggregates server-wide reading shelves; selected-library scope belongs to Libraries.
- The interface uses compact, touch-safe cards and controls with accessibility semantics, large-text support, and clear offline/error states.
- Startup should show usable cached content as soon as possible and avoid blocking/global progress indicators when content is already available.
- Native username/password and the implemented server-hosted sign-in WebView are supported; native AppAuth remains deferred by the upstream redirect contract.

## Current navigation and action contracts

- Book Detail keeps Read/Preview visible and exposes download/update/delete actions according to file state.
- Book Detail shows a compact full-width, two-line available-file summary above Synopsis whenever at least one supported file is available, keyed by file ID. A file-type badge sits at the left; the selected filename stays on one line and automatically scrolls when it exceeds the available width; size plus `Primary`/`Alternate` role and `Available offline` metadata (when applicable) is the stationary second line. The dropdown chevron and click-to-open behavior are shown only when more than one file exists; with exactly one file, the summary is a non-interactive display. Tapping a multi-file summary opens a bottom-sheet picker hosted as a sibling overlay outside the lazy Book Detail content. Unselected filenames stay on one line and ellipsize; the currently selected filename wraps to as many lines as needed to show the complete name without ellipsis. Selecting a row refreshes the underlying Book Detail selection and the sheet checkmark without replacing or closing the overlay; the user dismisses the sheet explicitly. Each row also shows a stationary file-type badge, size, role, and offline state. The selected EPUB/PDF/comic or audio file supplies the existing Read/Preview/Play and download actions; unknown attachments such as JSON are not selectable media versions. `Other versions` remains reserved for separate same-series, same-index records.
- Book Detail, Series, Author, and nested genre return state survive saved-instance-state recreation.
- Book Detail Previous/Next series navigation resolves each adjacent series index by preferring the current library and format family, then the same family across libraries in the user-visible library order. If that family is unavailable everywhere, it uses the first library with a target and the fallback families EPUB/KEPUB, PDF, CBZ/CBR/CB7, then audiobook; audiobook extensions such as M4A, M4B, and MP3 are one family.
- Offline Previous/Next must replace the visible Book Detail state using the selected target book/file identity without waiting for an online detail response. Cached series screens combine cached books from all available libraries rather than only the currently selected library.
- `Mark as...` exposes the complete BookOrbit status contract.
- Local books uses the completed-copy state, not an in-progress attempt, to decide whether `Delete local` is available.
- When a Local books or other normal open encounters a detail/network/preparation failure, the app attempts the completed local copy before showing the error. This fallback does not depend solely on the cached connectivity flag; missing local content keeps the original network error, while invalid local files and archive-extraction failures remain distinct errors.
- Active and failed download rows are conditional and remain separate from completed local content. The Local books Downloads section has an accessible expand/collapse control; its expanded rows scroll internally within a maximum half-screen-height body. Each title stays on one line with marquee overflow behavior, and an active row keeps `Cancel` to the right of its progress bar. A server 403 on a download is shown as a distinct permission-denied notice rather than the generic failed state, does not sign the user out or invalidate the session, and suppresses immediate `Retry` for that item until the permission-denied state is cleared or refreshed; ordinary transient/storage failures keep the existing `Retry`/`Clear` behavior. Browser-level download notifications and errors, including the permission-denied notice, render in a shared shell feedback layer owned by the browser screen, so they stay visible on the current destination, including Book Detail, without duplicating destination-local notices.
- On the Browse tab, collection actions sit below the library filter/count row. `Download library` appears only when the complete selected-library catalog contains a missing or updateable local file; it opens file-level selection grouped by library/format, then requires two sequential storage/data confirmations. Series detail uses the same eligibility rule and selection flow, with one whole-series confirmation and ascending series-index dispatch. Active series/library transfers show aggregate progress using the Book Detail progress treatment. `Delete local books` appears when the current series/library has local copies and always requires a count-aware confirmation; it removes only device files, not BookOrbit records. Metered bulk downloads show one cellular warning for the whole operation, never one warning per book. Dismissal or cancellation starts nothing; Shelves bulk download remains deferred because the current API/model path does not expose usable Shelf content.
- Pull-to-refresh is user-initiated, non-blocking, duplicate-safe, and independent from background synchronization and destructive download actions.
- The browser Home/Libraries/More navigation bar remains visible on Series detail, and Series detail uses the shared `PullToRefreshLayout` to reload its loader on pull while clearing the refreshing state on success or failure.
- Series includes a `Smart scopes` destination. It loads the server-provided scope names, shows a loading row, an error state (`Unable to load smart scopes.`), or an empty state (`No smart scopes found.`); selecting a scope opens the Series catalog under that scope. The scoped catalog fetches the scope's paginated books and derives Series cards locally, so its loading, error (`Unable to load series.`), and empty (`No series found.`) states follow the normal Series catalog behavior. The selected-scope catalog title is informational; More → `Smart scopes` is the explicit scope-switching entry point. Scoped catalog snapshots are retained per server/scope/filter/page for non-authentication failures, while authentication failures remain errors. Smart Scope Series covers use the same downsampled bitmap-cache path as Library covers, so scrolling a card away and back reuses its cached image instead of blanking and reloading it.
- Options exposes an Offline library cache card with multi-library selection, independent global Book details and Cover thumbnails switches, manual download/update, cancellation, progress/results, explicit clearing, and an optional approximately daily unmetered-network refresh. The control states that readable book files are not downloaded; deselecting a library does not silently delete its existing cache.
- Server-missing catalog records remain visible with a yellow `Missing!` overlay; this is distinct from a locally deleted copy.
- About contains one `Check for updates` button. It shows checking and result states; when an update is available, the existing update card is shown again.
- EPUB-only reader font controls include Publisher default, built-in normal/accessibility choices, and one imported custom font slot.
- EPUB text size is a persisted 90%–200% live-preview option, adjusted in 10% (0.1×) steps by the existing ± steppers; both steppers can reach the full range, and the same named-constant bounds are shared by preference normalization and the Readium font-size mapping.
- EPUB reader options open at approximately two-thirds of the available reader surface. The top handle is fixed outside the scrollable settings, exposes a minimum 48 dp touch target, and resizes the session-only sheet within bounded limits. EPUB line spacing is a persisted 1.0×–2.0× live-preview option, and default word spacing is a persisted 0.0–1.0 rem live-preview option; both are applied through Readium’s user CSS preferences.
- Reader tap zones are persisted per library. The default uses equal-width Previous / Menu / Next thirds; Vertical thirds provides full-width top / middle / bottom Previous / Menu / Next regions; Kindle, L-shape, Edge, and Menu-only layouts are also available, with independent None, Horizontal, Vertical, and Both inversion modes. Reading direction changes the horizontal action mapping without changing EPUB typography. Changing the tap-zone layout or inversion from reader options re-shows the tutorial over the reading surface while keeping the options sheet above it.
- The per-library `Turn pages with volume buttons` setting is off by default. When enabled, Volume Down invokes logical Next and Volume Up invokes logical Previous in EPUB, PDF, paginated comics, and continuous comics; an active unobstructed reader consumes those keys and suppresses the system volume overlay. The subordinate `Swap volume button actions` setting is enabled only when volume paging is enabled and reverses that mapping. Any active audiobook session disables reader page-turning and leaves volume keys to normal Android volume behavior, including paused playback. Disabled, loading/error/empty, unfocused, Preview-overlay, options, chrome, and tutorial states retain normal volume behavior. Audiobook playback, the audiobook player, and external media controls are unaffected.
- Preview opens EPUB/PDF/comic readers without saving progress, locators, active-reader state, or reading-session telemetry. A full-width status-bar-safe bar reads `Preview mode · Tap to enable reading progress`; confirmation promotes the existing reader in place and preserves its exact page or EPUB annotation locator. EPUB annotation Preview renders the selected annotation with its saved color/style and keeps it highlighted after promotion and repagination.
- Audiobook Preview uses a rounded card aligned with the compact player and reads `Preview mode · Tap to enable listening progress`. Tapping the card pauses playback before confirmation; cancel keeps it paused in Preview, while confirmation promotes the existing session at the exact timestamp and starts progress persistence without automatically resuming playback.
- Direct EPUB reads load all active annotation pages and render their saved highlights/underlines. Text selection retains Android’s Copy, Share, and Web search actions and adds Highlight and Highlight + Note; annotation-card overflow and long-press actions remain separate management paths for existing annotations.
- Audiobook session history presents Local listening history and Server reading history as separate, independently collapsible sections sharing the same server-style card/ListItem visual language; both sections start expanded. The Session history title, Clear, and Close controls remain fixed while the history body scrolls. Local entries are offline-capable, exact-position, and clickable for seeking. Server entries are analytics-only sessions/attempts and remain read-only because they carry no exact audio position; their loading, unsupported, error, and empty states are visible without blocking local history.
- The audiobook full player is a coordinator-owned overlay above the retained browser route. It provides cover viewing, title/series metadata, overall book and chapter seek bars, previous/next chapter, rewind/forward, play/pause, Chapter, Speed, Sleep, session history, lock mode, and Close. Minimize reveals the exact previous browser location; Close stops/removes the player without implicit navigation.
- The shared full-screen cover viewer, opened from Book Detail or either audiobook-player cover entry point, is an edge-to-edge dialog that centers the cover relative to the whole screen and fits it within a bounded aspect-ratio box in portrait and landscape, fitting portrait covers fully inside landscape. Pinch zooms between 1x and 4x with bounded pan, applying immediately. Tapping inside the currently visible cover resets zoom and pan to 1x; double-tap inside the cover toggles between 1x and a 2.5x preset zoom; long-pressing inside the cover opens a context menu without downloading. Tapping outside the currently visible cover dismisses the viewer, as does double-tapping outside it or pressing Back. Only tapping the menu's Download action saves the loaded image to `Downloads/Lagrange Reader` with a sanitized, collision-safe book-title filename and shows explicit Toast success or failure feedback. API 26–28 requests storage permission when needed; API 29+ uses scoped MediaStore. Missing image data, denied permission, and failed writes do not create partial files.
- The full player uses one shared Material 3 chapter `ModalBottomSheet` for compact and full entry points. It highlights the active chapter, seeks on selection, dismisses after selection, and uses sheet-owned navigation-bar geometry. Seek labels are centered between the elapsed and remaining timestamps: `Book progress` for the overall bar and `Chapter progress` for the chapter bar.
- Portrait and landscape use grouped height-responsive sizing rather than shrinking only the bottom buttons. The complete group reduces spacing, typography, cover allocation, seek-row height, and control artwork when constrained; Chapter, Speed, Sleep, and transport touch targets retain usable minimums. An overflowing one-line chapter title uses marquee auto-scroll, matching the existing book-title behavior.
- A connected split-MP3 audiobook is presented as one continuous audiobook: the compact player's time and slider use the complete duration, chapter and ±10/30-second seeks may cross file boundaries, and playback automatically continues into the next ordered file. Single-file and downloaded/local audio behavior is unchanged.
- EPUB/PDF/comic readers may recreate for orientation, screen-size, and fold changes, but must remain visible by reopening one navigator at the exact saved locator. Configuration recreation must not look like user closure, duplicate the reader, or clear active-reader state; process recovery is validated separately.

## Current visual rules

- Preserve meaningful touch targets and TalkBack semantics even when compacting visual layout.
- Prefer reusable Compose components and theme tokens over screen-local spacing and styling.
- Keep action rows stable at narrow widths; move optional actions into More rather than wrapping required actions.
- Wrap reader-option choice groups onto additional rows when the available width is insufficient; do not require horizontal swiping to discover the complete set of choices.
- Preserve current cover aspect ratios and bottom alignment for portrait and square covers.
- Keep reader controls, tutorial regions, orientation behavior, keep-awake behavior, and Preview isolation consistent across supported formats.
- Treat unavailable media as an explicit state rather than a generic empty or local-download failure.
