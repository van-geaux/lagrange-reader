# Roadmap

This document contains the current project direction only. Historical work orders and dated implementation logs are preserved locally in `docs/roadmap-archive.md` (ignored by Git, not part of the public documentation set).

## Current status

- Release: Lagrange 1.4.2 is published. See [`docs/release-notes/v1.4.2.md`](release-notes/v1.4.2.md).
- Recent completed work: behavior-neutral cleanup, release integration, pull-to-refresh, continuous EPUB seeking, reader fonts including one imported custom font, staged startup, server-missing catalog state, and download lifecycle implementation.
- Current implementation state: issue #23 reader-options resizing and persisted EPUB line spacing, the download lifecycle, indexed navigation, server reading sessions, issue #37 (Available file selection), issue #40 (persistent browser navigation), and issue #36 (multi-file streamed MP3 playback) are implemented and user-confirmed working. New implementation work is deferred; BOOX issue #25 remains pending physical-device access; issue #42 (cached series Previous/Next navigation fails offline) is implemented and user-confirmed. Delivery of these items into `main` still requires pull-request integration; see the local handover for current PR state.
- Highest-priority active feature: [#55](https://github.com/van-geaux/lagrange-reader/issues/55), “Synced highlighting and search.” The current worktree contains the global Annotations destination backed by BookOrbit's annotation hub, annotation-to-reader navigation for EPUB CFI/PDF page positions, EPUB text selection via Readium ActionMode, highlight/note creation and highlight/underline decorations, note edit/delete, durable offline annotation mutation synchronization through a local queue with WorkManager retry and local-to-server ID mapping, and isolated Preview rendering of the tapped EPUB annotation. PDF/comic annotation creation and publication full-text search remain pending.
