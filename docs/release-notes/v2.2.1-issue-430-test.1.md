# Lagrange 2.2.1 issue #430 test build

Release date: 2026-11-27

This prerelease lets BookOrbit, Komga, Kavita, and Grimmory users test the issue #430 reading-activity ordering fix before it is included in a stable release.

## Fixes

- Home Currently Reading and Android Auto Continue Playing/Now Playing now order in-progress books by the newer of provider-reported last-read activity and recent activity recorded locally on this device.
- Local activity is isolated by profile and authenticated account. It affects ordering only, preserving provider shelf membership, provider progress, and Kavita's existing per-series current-volume choice. Completed books and Preview are excluded.
- Foreground progress and Android Auto/text-to-speech playback activity use the same local ordering signal.

## Validation

- Local JVM regression suite passed: 1,583 tests.
- `lintDebug` passed with 0 errors and 169 warnings.
- Android-test Kotlin compilation and APK assembly passed; instrumentation was not run on a device.
- No real-provider or on-device validation has been performed for this prerelease.

## Reporter test request

Please install this prerelease and reproduce issue #430: listen to one in-progress book, play another, then resume the first and listen again. Confirm whether the first book moves to the front of Home Currently Reading and Android Auto Continue Playing/Now Playing for your provider. Also confirm that provider shelf membership and progress remain unchanged.
