# Lagrange 2.1.3

Release date: TBD

This release expands library discovery and reading options, improves provider integrations, and makes background downloads and audiobook controls more reliable.

## Highlights

- Browse server collections and similar lists across BookOrbit, Komga, and Kavita, and use provider-aware EPUB bookmarks. ([PR #394](https://github.com/van-geaux/lagrange-reader/pull/394), [PR #395](https://github.com/van-geaux/lagrange-reader/pull/395)) ([`RobinD42`](https://github.com/RobinD42), [`van-geaux`](https://github.com/van-geaux))
- Customize reading with optional title-and-author headers, EPUB margin tap zones, two-page comic spreads on larger displays, and improved EPUB layout handling. ([PR #390](https://github.com/van-geaux/lagrange-reader/pull/390), [PR #304](https://github.com/van-geaux/lagrange-reader/pull/304), [PR #413](https://github.com/van-geaux/lagrange-reader/pull/413), [PR #402](https://github.com/van-geaux/lagrange-reader/pull/402)) ([`RobinD42`](https://github.com/RobinD42), [`chortya`](https://github.com/chortya), [`RobinD42`](https://github.com/RobinD42), [`JimmyJi0309`](https://github.com/JimmyJi0309))

## Features

- [010bdf9](https://github.com/van-geaux/lagrange-reader/commit/010bdf9cbc9c126187beed28571ec2d8a5f74553) Added a Collections destination for BookOrbit collections and Smart Scopes, Kavita collections and Want To Read, and Komga collections and Read Lists. ([PR #394](https://github.com/van-geaux/lagrange-reader/pull/394)) ([`RobinD42`](https://github.com/RobinD42))
- [543142f](https://github.com/van-geaux/lagrange-reader/commit/543142fe422627434829e0da8c75fab76e07fc60) Added provider-aware EPUB bookmarks: BookOrbit supports list, add, open, edit, and delete; Kavita PToC text bookmarks support list, add, open, and delete. Kavita title/note editing is not supported, and Komga does not expose bookmarks. ([PR #395](https://github.com/van-geaux/lagrange-reader/pull/395)) ([`van-geaux`](https://github.com/van-geaux))
- [a7f98fc](https://github.com/van-geaux/lagrange-reader/commit/a7f98fc593d4218890624d28beeb49ffbafbd87c) Added optional per-library title-and-author headers and separators for EPUB, PDF, and comic readers. - [9dae559](https://github.com/van-geaux/lagrange-reader/commit/9dae5593e5476db2e34793fd1e244286cd1dbe08) Added an EPUB reader setting that lets taps and page-turn swipes respond within selected parts of the page margins. ([PR #413](https://github.com/van-geaux/lagrange-reader/pull/413)) ([`RobinD42`](https://github.com/RobinD42))
- [ea3ebff](https://github.com/van-geaux/lagrange-reader/commit/ea3ebff13a9b2a773c06f37cb9c3916feefe7774) Added two-page comic spreads on unfolded foldables and landscape tablets. ([PR #304](https://github.com/van-geaux/lagrange-reader/pull/304)) ([`chortya`](https://github.com/chortya))

## Others

- Known limitation: BookOrbit PDF progress changed in the web reader may not always appear when the same book is reopened in Lagrange. The fix is deferred to the next release ([#378](https://github.com/van-geaux/lagrange-reader/issues/378)).

## Upgrade notes

- No migration action is currently identified for the changes in this release. Existing profiles, downloads, cached data, and reader preferences are expected to remain available.
