# Lagrange v1.5.4-issue-197-debug-1

## Feature

- Added an `Immersive reading: hide status bar` option under General settings. It is disabled by default and independently controls the Android status bar for EPUB, PDF, and comic readers.
- When enabled together with the existing navigation-bar option, readers can use the full screen without either system bar. Audiobook playback is unchanged.

## How to try immersive status-bar hiding

1. Install the combined APK, the default download for most devices.
2. Open Options → General.
3. Enable `Immersive reading: hide status bar`.
4. Open an EPUB, PDF, or comic reader and verify that the status bar is hidden.
5. Disable the option to restore the default visible status bar.

## Validation

- The focused preference/system-bar tests, full JVM unit-test suite, Android lint, debug APK assembly, and Android-test APK assembly passed for the implementation.
- This prerelease provides a signed combined APK as the default download, with architecture-specific APK alternatives attached by the release workflow.
