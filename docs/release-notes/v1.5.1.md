# Lagrange 1.5.1

## Features

- [bedb5ee](https://github.com/van-geaux/lagrange-reader/commit/bedb5ee6b25cd82c3c601caedf56ae4eff39f3ca) Added Smart Scopes under Series. ([#111](https://github.com/van-geaux/lagrange-reader/pull/111), [#101](https://github.com/van-geaux/lagrange-reader/issues/101))
  - Discover server-defined Smart Scopes and browse their paginated books.
  - Derive a local Series catalog while retaining server-backed book and file identity.
  - Preserve scoped catalog and cover data for offline use, with fixes for initial loading and returning to normal Series browsing.
- [c9911cf](https://github.com/van-geaux/lagrange-reader/commit/c9911cffb18df20e42332a23fdd5167b40cbf126) Improved active-download notifications. ([#109](https://github.com/van-geaux/lagrange-reader/pull/109), [#103](https://github.com/van-geaux/lagrange-reader/issues/103))
  - Show per-download titles and progress with individual Cancel actions.
  - Show a summary notification for multiple active downloads and clean up terminal notifications.
  - Downloads continue when notification permission is denied.
