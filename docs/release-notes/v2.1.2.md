# Lagrange 2.1.2

Release date: 2026-11-02

This hotfix restores the audiobook notification player that was missing in Lagrange 2.1.1. We’re sorry for the regression and appreciate your patience while we corrected it.

## Highlights

- Restored the audiobook notification player missing in 2.1.1, including foreground media playback and a notification action that reopens the player. ([PR #382](https://github.com/van-geaux/lagrange-reader/pull/382)) ([`van-geaux`](https://github.com/van-geaux))
- Improved EPUB reading with more reliable progress and resume handling, optional paragraph spacing, additional reader themes, and guarded chapter transitions in continuous scrolling. ([PR #370](https://github.com/van-geaux/lagrange-reader/pull/370), [PR #369](https://github.com/van-geaux/lagrange-reader/pull/369), [PR #380](https://github.com/van-geaux/lagrange-reader/pull/380), [PR #385](https://github.com/van-geaux/lagrange-reader/pull/385)) ([`JBWortley`](https://github.com/JBWortley), [`RobinD42`](https://github.com/RobinD42), [`van-geaux`](https://github.com/van-geaux))
- Added a high-contrast colour e-ink theme and corrected visible-page progress in PDF reading. ([PR #347](https://github.com/van-geaux/lagrange-reader/pull/347), [PR #373](https://github.com/van-geaux/lagrange-reader/pull/373)) ([`JBWortley`](https://github.com/JBWortley), [`van-geaux`](https://github.com/van-geaux))
