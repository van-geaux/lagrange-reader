# Lagrange 2.1.1 issue #367 test build

Release date: 2026-10-31

This prerelease tests the corrected PDFium page-position handling for issue #367. It is intended for reporter validation on BookOrbit PDFs.

## Fixes

- Fixed PDF footers that displayed the first visible PDF page as page 2 instead of page 1.
- Corrected visible page progress for the first, intermediate, and last PDF pages while preserving PDF resume and progress synchronization behavior.

## Validation

- JVM regression tests passed for PDFium page-index correction and document bounds.
- Android instrumentation passed for opening a three-page PDF and reporting the first, intermediate, and last visible pages.
- Android lint, debug APK assembly, and Android-test APK assembly passed.
- The fix was exercised on a connected Android device before publication.

## Reporter test request

Please test several BookOrbit PDFs and confirm that:

- the first visible page displays as page 1 of the correct total;
- intermediate and last pages display the expected page numbers;
- tapping page 1 from the page list opens page 1;
- closing and reopening a PDF preserves the expected position.

This is a prerelease test build. Existing app data should be retained when updating from the regular 2.1.1 release, but please back up important data before testing.
