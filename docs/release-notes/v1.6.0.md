# Lagrange 1.6.0

Release date: 2026-10-07

## Highlights

- Update detection continues to use the GitHub latest-release API.
- Available updates continue to open the GitHub release page.
- Added a manually triggered signed Android App Bundle workflow for Google Play Console submission.
- Added Play release preparation guidance covering signing, testing tracks, metadata, and publication order.

## Release and distribution

- Android application id: `com.vangeaux.lagrange`.
- Version code: `26`.
- Google Play distribution uses the signed `app-release.aab` artifact from the `Android Play Bundle` workflow.
- GitHub APK assets continue to be generated by the existing tag-triggered release workflow.
- Google Play publication is deferred; GitHub remains the active distribution and update destination for this release.

## Verification

- Pull request JVM tests, Kotlin compilation, lint, debug APK assembly, and Android-test compilation/assembly passed for the update-dialog and Play workflow changes.
- Merged-main Android Debug CI passed after both changes were merged.
- Physical-device and Play-installed validation remain required before production rollout.
