# Lagrange 2.1.1

Release date: 2026-10-30

Lagrange 2.1.1 is a focused follow-up to 2.1.0. Its main purpose is to address crashes and loading failures when Kavita libraries contain many thousands of books and series, while also refining Komga and Kavita integration and including the other updates that landed after 2.1.0.

## Highlights

- Large Kavita libraries with many thousands of books and series now use safer, incremental, and paged loading instead of trying to load the complete catalog at once. This targets crashes, timeouts, and screens that previously failed to load. ([PR #345](https://github.com/van-geaux/lagrange-reader/pull/345), [PR #355](https://github.com/van-geaux/lagrange-reader/pull/355)) ([`van-geaux`](https://github.com/van-geaux))
- Kavita Home and series browsing preserve pagination totals, stable identities, cached content, and profile-scoped offline snapshots while more data is loaded. ([PR #355](https://github.com/van-geaux/lagrange-reader/pull/355)) ([`van-geaux`](https://github.com/van-geaux))
- Komga Library → Browse now uses the paginated book catalog, while Series remains available as a separate navigation path. ([PR #358](https://github.com/van-geaux/lagrange-reader/pull/358)) ([`van-geaux`](https://github.com/van-geaux))
- Downloads can now use supported folders selected through Android's Storage Access Framework, including internal shared storage, and EPUB integrity validation works across those selected-folder flows. ([PR #359](https://github.com/van-geaux/lagrange-reader/pull/359), [PR #363](https://github.com/van-geaux/lagrange-reader/pull/363)) ([`van-geaux`](https://github.com/van-geaux))

## Known limitations

- Kavita and Komga behavior still depends on the capabilities and response contracts of the configured server version.
- Live-server and device validation remain separate from automated build evidence.
- Provider-specific unsupported capabilities remain unavailable rather than being represented as successful empty operations.
- Custom EPUB colors do not automatically validate contrast, and PDF/comic custom appearance remains out of scope.

## Validation

- Kavita catalog-loading verification passed for the changes in PR #345.
- PR #355 passed 1,163 JVM tests, Android-test compilation, lint, debug APK assembly, and Android-test APK assembly.
- PR #358 passed through the required `build-and-test` workflow.
- PR #348 and PR #353 include contributor-reported physical-device validation for their respective reader features.
- Kavita and Komga live-server validation should remain separate from general automated build evidence.
- PR #363 included contributor-reported device validation of a Kavita EPUB download to a user-selected phone folder; BookOrbit and Komga share the implementation path but were not separately device-tested for this release note.

## Upgrade notes

- Existing BookOrbit, Komga, and Kavita profiles, local downloads, cached data, and reader preferences should be retained. Existing downloads remain available; newly selected folders are used for subsequent portable downloads.
- No migration action is currently identified for the 2.1.1 provider integration updates.
