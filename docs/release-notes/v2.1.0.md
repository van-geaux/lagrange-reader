# Lagrange 2.1.0

Release date: 2026-10-27

Lagrange 2.1.0 brings the app to three supported book servers: BookOrbit, Komga, and now Kavita. This release makes Lagrange a more flexible home for your library, whether you host one server or use several, while continuing to focus on a native, offline-first Android reading and listening experience.

## Others

- Lagrange now supports BookOrbit, Komga, and Kavita. You can choose the provider explicitly when adding or changing a server profile.
- Kavita support is intentionally focused on its available contract. Authors, annotations, statistics, achievements, Smart Scopes, audiobook downloads, and server reading-session history remain unavailable or hidden rather than being presented as successful no-op features.
- Kavita's supported EPUB, PDF, comic, download, and Local Books paths use the same native Android reading experience while retaining provider-specific authentication and identity handling.
- Normal combined APK: `Lagrange-2.1.0.apk`
- ARM alternative: `Lagrange-2.1.0-arm.apk`
- 32-bit x86 alternative: `Lagrange-2.1.0-x86.apk`
- 64-bit x86 alternative: `Lagrange-2.1.0-x86_64.apk`

If you are unsure which architecture to choose, download the plain combined APK.

## Known limitations

- Some EPUB/PDF publications may still fail Readium preparation on particular files or devices. Reader recovery has been improved, but the remaining cases tracked in [issue #292](https://github.com/van-geaux/lagrange-reader/issues/292) are not resolved by this release.
- Current-device validation for the final release artifact remains separate from the automated build and is not claimed here.

## Validation

- Local automated verification passed for compilation, unit tests, lint, debug APK, and Android-test APK: 1,113 JVM tests with 0 failures, 0 errors, and 0 skips; lint reported 0 errors and 82 warnings.
- Release APK and Play AAB assembly require the CI signing secrets and must be verified by their respective release workflows.
- No connected device was available during release preparation, so provider/device validation is not claimed here.

## Upgrade notes

- Existing BookOrbit, Komga, and Kavita profiles, local downloads, and reader preferences should be retained.
- Kavita users can add a Kavita profile from the server-selection flow.
- Automatic downloads remain disabled until enabled by the user.
- No migration action is currently identified for the 2.1.0 changes.
