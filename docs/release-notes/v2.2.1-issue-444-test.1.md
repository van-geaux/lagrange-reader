# Lagrange 2.2.1 issue #444 test build

Release date: 2026-11-27

This tester prerelease lets EPUB readers validate compatibility handling for third-party Android text-to-speech engines that report voice-quality metadata Readium does not recognize. This is not a stable release.

## Fixes

- [6cad0d77](https://github.com/van-geaux/lagrange-reader/commit/6cad0d77a9d4fe1d12009894a109e6894dd89f01) Unknown Android voice-quality metadata is adapted to Readium's Normal quality without replacing the selected Android voice. Playback waits for explicit confirmation; canceling closes TTS while leaving the EPUB reader open. ([issue #444](https://github.com/van-geaux/lagrange-reader/issues/444))

## Tester request

Please install this prerelease and test with a third-party Android TTS engine that reports an unsupported voice quality (the reported issue included quality `0`). Confirm that the warning appears before speech, Continue reads using the selected engine and voice, and Cancel stops TTS without closing the EPUB reader. Also check a voice with a supported quality and report your device, Android version, engine/version, selected voice, and results.

Once published, download this tester build directly from this GitHub release; the normal update checker does not offer prereleases. Back up important data before testing.
